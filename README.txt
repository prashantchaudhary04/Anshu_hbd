ANSHIKA'S 20TH BIRTHDAY WEBSITE 🎀

OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the folder "Anshika_Birthday_Website".
3. Double-click index.html. It opens in your browser.
4. Enter exactly: Anshika
5. Enjoy the gifts, photos, cake and birthday tune!

HOW TO REPLACE THE 4 PHOTOS
1. Inside the website folder, open the "photos" folder.
2. Replace photo1.jpg, photo2.jpg, photo3.jpg and photo4.jpg with your own pictures.
3. Keep the exact same filenames and use JPG images for easiest replacement.
   (If your photo is PNG, convert it to JPG or update the matching image filename in index.html.)
4. Refresh index.html in the browser.
5. To change the little captions under photos, open index.html in Notepad or VS Code and search for "Birthday girl energy", "Ek dum main character", "Good people, good memories", or "One for the memory book".

The website includes four placeholder image cards. If the photo files are not present, it displays pastel placeholder cards instead.
To change the accepted name, edit this line near the bottom of index.html:
const correctName = "Anshika";

The page works without installing anything. Internet is only needed for optional Google Fonts and placeholder images if the local photos are not added.
